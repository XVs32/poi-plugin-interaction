# poi-plugin-blank

A minimal blank plugin scaffold for the POI browser 

## Contents

- `package.json` — package metadata and POI entry point
- `index.es` — empty plugin panel, empty settings panel, and lifecycle hooks

## Install for local development

1. Open POI.
2. Open the plugin/extension settings.
3. Install the plugin from its local package/folder if your POI build exposes that option, or package/publish it to a package registry and install it by package name.
4. Restart or reload the plugin if required by your POI version.

This is a starter scaffold only. It does not access game state, inspect API traffic, or register any event handlers.
